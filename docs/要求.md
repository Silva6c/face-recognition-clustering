# 人脸识别与聚类系统 — 实训要求

## 一、具体任务

### 1. 分类：搭建人脸识别系统

- 通过识别输入人脸图像对应的身份，完成**分类任务**
- 应用所学分类模型（如 **KNN、决策树** 等）

### 2. 聚类：完成人脸图像的聚类

- 通过将相似人脸图像聚类到同一簇，完成**数据聚类任务**
- 应用所学聚类模型（如 **KMeans、层次聚类、DBSCAN** 等）

---

## 二、要求

1. 基于附件中的模板提交实训报告
2. 完成人脸识别系统的搭建并演示，要求：
   - (1) 至少能识别 **5 个不同的明星**
   - (2) 能识别**自己的脸**
3. 完成人脸聚类系统的搭建并演示
4. 提交包含两个系统的实验报告（Word 或 PDF 文档）
5. 提交系统实现的实验代码（`.ipynb` 文件或 `.py` 文件）
6. **独立完成**，雷同报告和代码无成绩
